Below is a working demo of the Javascript port of Fireboy and Watergirl. Make sure you've clicked into the demo before pressing "Q" to start playing.
I've noticed issues for those using lower-end hardware or with many tabs open. If you ever find yourself "soft-locked", use ctrl+f5 to refresh the page.
At this time, the game contains no saving features. If you navigate away from this page or refresh for any reason, you will be sent back to the start.
